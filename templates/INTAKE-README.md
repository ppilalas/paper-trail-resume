# Drop your documents here

Everything in this folder stays on your computer. It is never committed.
The agent reads these files to build your evidence data store, so every
resume it writes later can be traced back to something you actually did.

Any format works: PDF, Word (.docx/.doc), Pages, RTF, Markdown, plain text.
File names do not matter.

## Required

- **Your past resumes. As many versions as you have.** Old versions matter:
  each one tends to keep bullets, metrics, and tools that later versions cut.
  Targeted resumes you sent for specific jobs count too.

## Strongly recommended

- **LinkedIn profile export.** On LinkedIn, open your profile, choose
  *More → Save to PDF*, and drop the file here.
- **Cover letters** you have sent. They often explain the story behind a
  result.
- **Performance reviews, promotion write-ups, or a brag document.** These are
  the best source of verified metrics and scope (team size, budget, revenue).

## Helpful if you have them

- Portfolio or work-sample links (paste them into a `links.md` file here).
- Case studies, award or certification lists, conference talks, articles.
- Job descriptions for roles you are targeting now, so the agent knows which
  evidence to dig for first.

## What not to add

- Government IDs, compensation documents, reference contact details, or
  anything you would not want summarized into a resume.

When you have added everything, tell the agent "that's everything." It will
keep asking until you do.
